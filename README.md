# Viewfinder

把 iPhone Duo 变成一台中画幅腰平取景相机。

把手机横过来半折成 90°，像一台小笔记本电脑：有摄像头的那一半竖起来，镜头朝前；另一半平放，屏幕朝上，当作取景屏。把手机端在腰间，低头看取景，就像用一台 6×6 的老相机。

## 功能

- **自动进入腰平模式**：通过 iOS 27.1 的 `GeometryProxy.reservedRegions(kind: .division)` 检测折痕，横向半折时自动切换成上下两半的布局。
  - 上半屏（竖着）：遮光罩背板，显示折叠角度（`onHingeChange`）和设置入口。
  - 下半屏（平放）：只有正方形取景屏和旁边的快门；其他按钮在上半屏。
- **取景屏质感**：正方形裁切、磨砂颗粒、菲涅尔环、中心亮斑和暗角。设置里可以打开“镜像取景”，像真正的腰平取景器那样左右相反（默认关闭）。
- **自动转正**：半折时 iPhone Duo 选的横屏方向是反的，app 会让系统换到另一个横屏方向。使用前需要在控制中心关闭竖排方向锁定。
- **哈苏风格色调**：取景屏实时预览和存下来的照片使用同一套调色，具体见下面“色调”一节。
- **可换对焦屏**：全磨砂、三分线、方格、裂像（裂像只是刻线样式，不能真正用来对焦）。
- **2× 焦距（约 48mm）**：接近哈苏 80mm 标准镜头在 6×6 上的视角，可切回 1×。
- **曝光补偿**：在 ±0、−0.3、−0.7、−1.0、+0.3、+0.7 之间循环。按 recipe 的建议，压低曝光可以让阴影更深，同时保住高光。
- **放大镜**：模拟弹出式放大镜，把画面中心放大 2.6 倍，方便精确对焦。
- **点按对焦和测光**。
- **拍照**：快门按下时画面短暂黑屏（模拟反光镜抬起），照片以传感器最高分辨率（48MP）拍摄，裁成正方形后存进相册。可以选择保存正常方向还是镜像。
- 展开放平、合上或竖着拿时，自动退回普通的正方形取景器。

## 色调

参考 r/iPhone17Pro 上一份把 iPhone 照片调成哈苏风格的 recipe，所有调整合成一张 33³ 的 3D LUT（`Camera/HasselbladLook.swift`）：

| recipe 中的项目 | app 里的做法 |
| --- | --- |
| Cool 摄影风格（冷底色带自然暖意）、Warmth −8、Tint +2 | 线性光下的通道增益：R ×0.975、G ×0.996、B ×1.025 |
| Exposure +10 | +0.12 EV |
| Highlights −40、Shadows +30、Contrast −15，以及 Stage Two 的曲线 | 一条单调曲线：黑点略抬起（0 → 0.025），1/4 处 0.25 → 0.27，中间调 0.5 → 0.52，3/4 处 0.75 → 0.755，白点压到 0.965 |
| Vibrance −10 | 饱和度越低的颜色降得越多 |
| Blues 饱和度 +5、明度 −5 | 色相 215° 附近 |
| Greens 色相 +5、饱和度 −8 | 色相 115° 附近，色相 +4° |
| Sharpness +10 | 仅用于照片：`CISharpenLuminance` 0.25 |
| 关闭 Smart HDR | 设置里的“自然影调”（默认打开），拍照时用 `.speed` 质量优先级，减少多帧合成 |
| 48MP | 使用传感器支持的最大照片尺寸 |
| 48mm 焦距 | 默认 2× |
| 3×3 网格 | “三分线”对焦屏 |

Photos 里各个滑杆的算法没有公开，上面的数值都是近似值，可以在 `HasselbladLook` 里继续微调。ProRAW 暂时没有做：DNG 套不上这套色调。

## 运行

需要 **Xcode 27.1 或更新版本**（带 iOS 27.1 SDK），因为铰链和折痕 API 是 iOS 27.1 才有的。

1. 用 Xcode 打开 `WaistLevelFinder.xcodeproj`。
2. 选中 WaistLevelFinder target，在 **Signing & Capabilities** 里选择你的 Team。如果提示 Bundle Identifier 冲突，把 `com.marskwan.WaistLevelFinder` 改成你自己的。
3. 连上 iPhone Duo，Run。

## 代码结构

```
WaistLevelFinder/
├── App/          入口和设置项
├── Camera/       AVFoundation：会话、预览、拍照、存相册
├── Viewfinder/   取景屏：镜像、对焦屏刻线、磨砂质感、暗角
└── Screens/      布局（腰平模式 / 手持模式）、遮光罩、控件、设置
```

- `FinderLayout` 根据折痕位置统一计算所有控件的位置。取景视图在两种布局之间始终是同一个视图，切换时相机预览不会重建。
- 画面方向由 `AVCaptureDevice.RotationCoordinator` 计算。如果半折时方向不对，可以在设置里用“画面旋转校正”调整。

## 待在真机上确认

这个工程是在没有 Mac 的环境里写的，**还没有编译和真机测试过**。第一次运行请重点看：

- 能否顺利编译（Swift 6、iOS 27.1 SDK）。
- 半折时是否自动进入腰平模式，上下两半的方向对不对。
- 竖着的那一半是不是摄像头那一半。如果镜头朝下，把手机转 180° 再折。
- 取景画面和拍出来的照片方向是否正确。
