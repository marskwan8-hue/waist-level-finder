# 腰平取景 · Waist Level Finder

把 iPhone Duo 变成一台中画幅腰平取景相机。

把手机横过来半折成 90°，像一台小笔记本电脑：有摄像头的那一半竖起来，镜头朝前；另一半平放，屏幕朝上，当作取景屏。把手机端在腰间，低头看取景，就像用一台 6×6 的老相机。

## 功能

- **自动进入腰平模式**：通过 iOS 27.1 的 `GeometryProxy.reservedRegions(kind: .division)` 检测折痕，横向半折时自动切换成上下两半的布局。
  - 上半屏（竖着）：遮光罩背板，显示折叠角度（`onHingeChange`）和设置入口。
  - 下半屏（平放）：正方形取景屏，左边是工具，右边是快门和计数窗。
- **取景屏质感**：正方形裁切、**左右镜像**（和真正的腰平取景器一样）、磨砂颗粒、菲涅尔环、中心亮斑和暗角。
- **可换对焦屏**：全磨砂、方格、裂像（裂像只是刻线样式，不能真正用来对焦）。
- **放大镜**：模拟弹出式放大镜，把画面中心放大 2.6 倍，方便精确对焦。
- **点按对焦和测光**。
- **拍照**：快门按下时画面短暂黑屏（模拟反光镜抬起），照片裁成正方形后存进相册。可以选择保存正常方向还是镜像。
- **12 张一卷的计数窗**，和 120 胶卷 6×6 后背一样。
- 展开放平、合上或竖着拿时，自动退回普通的正方形取景器。

## 运行

需要 **Xcode 27.1 或更新版本**（带 iOS 27.1 SDK），因为铰链和折痕 API 是 iOS 27.1 才有的。

1. 用 Xcode 打开 `WaistLevelFinder.xcodeproj`。
2. 选中 WaistLevelFinder target，在 **Signing & Capabilities** 里选择你的 Team。如果提示 Bundle Identifier 冲突，把 `com.marskwan.WaistLevelFinder` 改成你自己的。
3. 连上 iPhone Duo，Run。

## 代码结构

```
WaistLevelFinder/
├── App/          入口和设置项
├── Camera/       AVFoundation：会话、预览、拍照、存相册
├── Viewfinder/   取景屏：镜像、对焦屏刻线、磨砂质感、暗角
└── Screens/      布局（腰平模式 / 手持模式）、遮光罩、控件、设置
```

- `FinderLayout` 根据折痕位置统一计算所有控件的位置。取景视图在两种布局之间始终是同一个视图，切换时相机预览不会重建。
- 画面方向由 `AVCaptureDevice.RotationCoordinator` 计算。如果半折时方向不对，可以在设置里用“画面旋转校正”调整。

## 待在真机上确认

这个工程是在没有 Mac 的环境里写的，**还没有编译和真机测试过**。第一次运行请重点看：

- 能否顺利编译（Swift 6、iOS 27.1 SDK）。
- 半折时是否自动进入腰平模式，上下两半的方向对不对。
- 竖着的那一半是不是摄像头那一半。如果镜头朝下，把手机转 180° 再折。
- 取景画面和拍出来的照片方向是否正确。
